# 개발·유지보수 백로그

기존 구현의 재개발 목록이 아니라 변경 요청을 분류하는 틀이다. 완료 여부는 최신 코드·progress·실행 검증으로 판단한다.

| 순서 | 범위 | 선행 조건 | 검증 |
|---|---|---|---|
| 기반 | 공통·MAT/BAS/SYS/DAT | 정본·계약·권한 | ID·입력·행위 권한 |
| 업무 | PRC/SHP·LOT | 마스터·원재료·발효 이력 | 정/역추적·포장·출하·검사 |
| 발효 ML | FMT·학습 데이터 | 표본·라벨·평가 분할 | G-12~G-15, 실측/합성 구분 |
| Agent | AGT·입고/출하 Agent | 데이터·문서·LLM 구성 | 인용·판단 불가·G-16/G-17 |
| 분석 | 대시보드·KPI | 집계·목표 근거 | 표/차트/SQL 일치 |
| 인수 | 전체 게이트 | 변경별 검증 | 차단·가설·운영 조건 명시 |

| 작업 | 화면/요구사항 | 근거·결정 | 변경 파일 | 의존관계 | 상태 | 검증 |
|---|---|---|---|---|---|---|

이번 문서 작성에서 앱 게이트를 실행하지 않았다.
