# 평창김치 AI 플랫폼 개발 템플릿 규칙

이 킷은 참고 지침이다. 앱 루트 CLAUDE.md·goal.md·contracts·decisions.md·progress.md를 먼저 읽는다. 루트 규칙을 이 파일로 덮어쓰지 않는다.

- 공정은 입고/보관 → 절단/전처리 → 세척/절임 → 선별 → 탈수 → 혼합 → 숙성/발효 → 금속검출 → 포장/출하다.
- AI 대상은 원재료 입고·숙성/발효·포장/출하. 업무 자동 반영·설비 제어를 추가하지 않는다.
- 기술은 Python 3.12/uv·FastAPI/Jinja2·PostgreSQL 17. 소스는 src/kkotsuni, 포트 8000, DB kkotsuni_db.
- MES-AD2 요구사항·MES-TD3 화면·MES-TD4 프로그램 ID와 정본 문구를 보존한다.
- 조회·대상별 쓰기·행위 권한을 각각 검사한다(D-26). 출하 승인 권한은 D-28을 따른다.
- DB는 conn.q/x/tx, 화면은 templating.render/base.html, 탭·팝업은 tabs.js를 재사용한다.
- LOT 추적의 SHP 대리키(D-16), 감사 MENU_CODE(D-18), 가설 표시(D-22), HTML 오류 처리(D-25/D-27)를 확인한다.
- AI 답변에 근거 인용을 남긴다. 근거 없음은 판단 불가, 미구성은 501. 합성 성능을 생산 성능으로 보고하지 않는다.
- 공용 파일 담당 경계를 지킨다. 이 킷은 자동 병렬 에이전트 기동 지시가 아니다.
- 비밀·쿠키·실데이터를 출력하지 않는다. goal.md와 정본을 임의 변경하지 않는다.
- 문서 검증 때문에 DB를 초기화하거나 시드를 재실행하지 않는다.
- 변경 파일·실행 검증·미실행·제약을 보고한다. push·배포는 사용자 지시 범위에 따른다.
