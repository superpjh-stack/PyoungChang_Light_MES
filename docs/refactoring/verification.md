## 검토에서 발견·수정한 사항

- Decimal을 포함한 422 오류 응답을 JSON으로 직렬화하도록 수정.
- Excel 내보내기의 문서 헤더·주문 상세·원 주문 참조·합계 보존.
- 발행과 지시수량 변경의 경쟁을 동일 잠금으로 보호하고 발행 후 출고 수량 변경을 차단.
- 날짜 순서가 반대인 동시 업로드의 교착을 배치 잠금으로 방지.
- 중첩 JSON/비문자 필드를 검증하여 정상 주문 그룹은 등록하고 잘못된 그룹만 거부.
- 컨테이너에서 이관 도구가 기존 Node 소스에 의존하지 않도록 SQLite 스키마 사본 포함.

독립 검토의 세 가지 재현 결함은 수정 후 범위 재검토를 통과했다. 근거 테스트와 이관 테스트 18건도 별도 재확인했다.

## 미실행·범위

- 운영 SQLite 데이터의 실제 복사, 기존 운영 앱 종료, 운영 배포, push/PR/merge는 수행하지 않았다.
- 기존 React/Express 소스와 작업 전 미커밋 변경을 보존했다. 기존 Vitest 사전 실행은 134/136 통과, 2건 socket hang up이었다. Python 검증 결과와 구분한다.
- 원본 제조 AI 플랫폼의 정본 설계·D-26/D-28 계약을 확보하지 않았다. 47개 화면·56개 테이블·발효 ML·RAG 게이트 달성을 주장하지 않는다.
- 현재 R1의 공개 조회/일반 쓰기와 역할 정책을 유지한다. 개발 계정 선택은 opt-in이며 운영 인증은 별도 구성 대상이다.
- HTML 입력 오류는 값을 유지하는 오류 응답이다. 정본이 없는 D-27의 303 오류 팝업 규약과 동일하다고 주장하지 않는다.
- 실제 ERP 공급자의 확정 Import 포맷 검증은 수행하지 않았다. 기존 CSV 구조와 수동 반영 흐름을 보존했다.
- 브라우저 증거는 `artifacts/browser/`에 저장했고 Git에는 포함하지 않았다.
- 원래 8000 포트가 사용 중이어서 기존 프로세스는 유지했다. 검증에는 임시 포트와 8019를 사용했다. 앱 기본 포트는 8000이다.
