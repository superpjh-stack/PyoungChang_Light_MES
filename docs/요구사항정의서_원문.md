1. 문서 개요
1.1 목적
본 문서는 평창꽃순이(주)농업회사법인의 추가요구사항 1번 「주문 내역서–출고 지시서–거래 명세서 연동 시스템 구축」에 대하여 도입기업의 요구를 기능·비기능·인터페이스·데이터 관점으로 명확히 정의하고, 이후 설계·개발·시험 단계에서 요구사항 ID 기반으로 추적할 수 있도록 하는 것을 목적으로 한다.
1.2 적용 범위
	•	대상 업무 : 거래처 주문 접수 → 주문 내역서 작성 → 출고 지시서 생성 → 거래 명세서 발행 및 ERP 입력
	•	대상 시스템 : 기존 MES(2025년 12월 구축, 현재 미운영) 내 주문·출고 기능 개선 및 신규 기능, ERP(뉴젠솔루션) 연동 인터페이스
	•	제외 범위 : 원부자재 재고 관리(2순위 과제로 별도 추진), ERP 내부 회계·세금계산서 발행 로직 변경

	•	주문 내역서 데이터 한 번 입력으로 출고 지시서와 거래 명세서가 생성되어야 함 (주문 내역서가 모든 컬럼을 포함)

5) 문자열 정규화(공백·특수문자 제거, 대소문자 통일) 후 유사도 기반 후보 제품 추천

8. 제약사항 및 전제조건
구분
내용
전제 1
도입기업은 주문 내역서 샘플 1건, 출고 지시서 샘플 1건, ERP 연동 정보를 분석 착수 전 제공한다.
전제 2
제품 표준 마스터(표준명·코드)는 도입기업이 확정하고, 거래처별 별칭 초기 데이터는 기존 엑셀 이력에서 추출한다.
전제 3
ERP 연동 방식은 뉴젠솔루션 측 지원 범위 확인 후 확정하며, 확정 전에는 표준 파일 방식으로 설계한다.
제약 1
시뮬레이션(실데이터 검증)은 2027년 1월 이후 착수하며, 데이터 연결관계 분석은 2026년 12월까지 완료한다.
제약 2
기존 MES 구조를 최대한 유지하고, 주문·출고 기능은 개선 방식으로 접근한다.
제약 3
성수기(김장철, 11~12월) 현장 담당자 인터뷰 및 검증 일정은 업무 부하를 고려하여 조정한다.
제약 4
본 요구사항 완료 후 2순위 과제(원부자재 재고 관리)를 착수하며, 마스터 데이터 구조는 2순위 과제와 공유 가능하도록 설계한다.
